# Kilometer-to-Miles-Calculator

## Description
This is a Python program that converts a given distance from kilometers to miles.

## How to Run
1. Access the file in VS Code, Replit, or Google Colab.
2. Run the program.
3. Enter the distance in kilometers.
4. Check the converted distance in miles displayed on the screen.

## Input Required
- Distance in kilometers (km)

## Sample Input/Output
Enter distance in kilometers: 10  
Distance in miles: 6.21371
